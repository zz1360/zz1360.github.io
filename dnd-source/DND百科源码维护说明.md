## 阅读与维护

[线上百科](https://blog.luckydogs.top/dnd/) · 非官方知识导览。

本目录包含可独立构建的源码、知识数据和全部 57 幅 WebP 原图。主站已迁移到 Astro；GitHub 仓库的 `site-source` 分支保存当前主站及本目录源码，`main` 分支用于 GitHub Pages 发布静态网页。当前日常维护入口是主站项目的 `dnd-source/`，原 `dnd-source` 分支及 VuePress 工作目录仅作历史保留。

## 构建

需要 Python 3。生成在线图片尺寸还需要 `cwebp`（macOS 可使用 `brew install webp`）。无需 npm 安装即可单独构建百科：

```sh
python3 dnd-source/build.py \
  --offline '/绝对路径/DND世界百科（插图版）.html' \
  --online '/绝对路径/dnd'
```

在线文件默认以 `/dnd/` 为网址前缀；部署到其他路径时需修改 `export_online.py` 中的资源前缀和 canonical。离线 HTML 内嵌全部文字、插图与脚本，可独立打开。外部资料链接需要联网。

在当前 Astro 主站项目目录执行 `npm run update:dnd` 可生成 `public/dnd/`，再由 `npm run build` 复制到输出目录。普通构建仅在该目录缺失时自动生成百科；修改本目录源码后请显式运行 `npm run update:dnd`。主站发布、文章写作和字体说明见项目根目录的 `维护说明.md`。

## 编辑位置

| 文件 | 用途 |
| --- | --- |
| `data.json` | 78 个条目的内容、年代、身份、英文名与来源 |
| `relations.json` | 双向阅读关联：两端 ID、关系标签、适用范围和来源键 |
| `history-flow.json` | 13 个历史节点的前因、事件、后果及来源 |
| `render.py`、`enhancements.py` | 页面模板、地图示意与功能面板 |
| `app.js`、`explore.js`、`cosmos.js` | 原有交互、链接与收藏、三维位面图 |
| `style.css`、`explore.css` | 阅读排版与探索工具样式 |
| `art-manifest.json`、`gallery-manifest.json` | 原画、女性系列画廊及艺术演绎说明 |
| `assets/` | 30 幅原画与 27 幅画廊图；不覆盖原图 |
| `build.py`、`export_online.py` | 离线构建、在线导出与响应式图片 |

每条新关联都应给出来源与范围。主题关联和年表先后不能写成直接因果；不同世界和版本的年代也不能合并成统一世界史。地图只作为方向导航，不提供比例、距离或准确坐标。插画不作为官方人物外貌、服饰或已发生事件的证据。

在线版保留完整原图，并生成 320px 缩略图和 640/960px 阅读尺寸。文件名包含原图校验值与编码参数，更新原图会更换资源名。`manifest.json` 保存全部原图与派生图片的 SHA-256 校验值。收藏与最近阅读只保存在浏览器本地，未增加登录或云端存储。

## 衍生作品

左侧新增“衍生作品”栏目，目录网址为 `/dnd/#works`。当前收录《阴魂》，专题网址为 `/dnd/works/yinhun/`，专题顶栏可返回目录。百科搜索同时检索作品标题、作者、简介及收录范围；小说内容保留独立设定与章节依据。

- `works.json`：作品 ID、标题、简介与源文件位置。
- `works/yinhun/source.html`：从用户提供的《阴魂》HTML 导入的维护副本；已省略本地文件路径。用户的原始 HTML 不会被构建脚本修改。
- `works.py`：作品目录渲染、现有《阴魂》模板的在线适配、图片导出与返回导航。
- `works.css`：目录卡片样式。

日常更新《阴魂》时，把新版整页 HTML 保存到 `works/yinhun/source.html` 后重新构建。卷、事件、人物数量和收录范围从页面中的 `atlas-data` 读取。当前适配器支持此专题的 HTML 结构；其他结构的作品应补充对应适配器，避免直接拼接两份脚本或样式。

在线专题保留 39 幅不同原始 WebP 的完整字节，另生成 320/640px 显示尺寸；首页、人物卡和关系图使用小图，弹窗按屏幕选择尺寸。剧情、人物、画廊与章节依据来自所提供文件，未对原 EPUB 进行新一轮内容审校。公开页面将“本机文本”调整为“所提供的文本”，省略绝对文件路径，保留章节索引和文本范围。

单文件百科仍可离线打开“衍生作品”目录及封面；作品按钮指向线上专题。原始《阴魂》HTML 继续支持独立离线阅读。

## 剧透保护、百科对照与阅读备份

《阴魂》在线专题首次进入默认使用“无剧透介绍”，可主动切换“按已读进度查看”（按卷末）或“允许完整剧透”。模式与已读卷数存于 `dnd-work-yinhun-reading-v1`，不会自动因查看专题而增加已读卷数。

原始卷纲第一卷已引用第六卷反转，不能仅按卷隐藏原稿。进度模式改用对应卷的事件标题与行动；暂不展示综合卷纲、事件前因后果、世界观长文、历史讲述、完整人物关系与未解线索。人物只保留已读卷内的行动；未知人物与收藏标签隐藏真实名字；画廊标题换成中性序号。已批准图片保留，视觉演绎本身可能含服饰或形象线索。打印遵循当前展示范围。保护针对网页展示，完整内容仍存在于静态文件中，不作数据加密或访问控制。

- `reader.py`：为在线专题及百科插入功能。保持 `works/yinhun/source.html` 不变。
- `works/yinhun/reader-bootstrap.js`、`reader.js`、`reader.css`：剧透范围、阅读恢复、收藏、来源过滤及手机布局。
- `works/yinhun/lore.json`：四组官方概念与小说用法的人工对照，含百科 ID、官方来源、小说章节索引、对应范围和核对日期。
- `reader-backup.js`、`works-desk.js`：本地备份校验、合并，以及百科中的作品收藏入口。

首批概念为物质位面、莎尔、密斯特拉与魔网。依据 D&D Beyond 官方 2014 基础规则核对基础概念，不把第五版资料等同于小说的年代与具体机制。译名对应及待核实差异单独说明；尚未核实的细节不直接标为作者改写。关联只建立在专题和百科之间的阅读入口，未修改基础知识数据或小说情节。

作品记住最近打开的卷纲、事件、人物与画廊位置，可收藏作品及这些记录。百科原有收藏与最近阅读仍使用原键 `dnd-codex-reading-v1`。从专题或百科的阅览桌导出的 JSON 同时包含这两组记录。导入校验版本、ID、记录类型和大小，合并收藏，保留当前剧透模式与卷数；不会因为备份来自完整剧透模式而自动解锁。清空作品阅读位置不会清空收藏或剧透设置。没有账户、自动跨设备同步或服务器存储；换设备需手动导出、导入。

新增人物、事件或卷数时，需要同步 `reader.py` 与 `reader-backup.js` 的范围及校验规则，再运行浏览器回归检查。跨卷反转不能只靠来源所在卷来自动判断；扩充进度模式的叙述前应人工核对揭示时间。

本轮浏览器验证通过：三种模式、降低进度、受限搜索、章节依据、打印范围、四组双向关联、卷与事件恢复、人物画廊序号恢复、收藏合并、非法备份拒绝、存储禁用降级、390px/320px 手机布局与真实横滑。完整模式回归保留 14 卷、66 个事件、12 位人物和 9 组画廊；39 幅原图与 78 张响应式图片校验值均与上一版一致，原始独立 HTML 未改动。

存储被禁用时，导出也可保存当前页面内存中的进度与收藏；其他页面无法读取的记录不会凭空恢复。该降级分支已通过浏览器验证。
